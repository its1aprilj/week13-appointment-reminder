\# Week 13: Automated Appointment Reminder System



\## Project Overview

This project is the initial Flutter frontend for an Automated Appointment Reminder System developed for Week 13.



\## Technology Used

\- Flutter

\- Dart

\- Material Design

\- Laravel REST API integration (backend maintained separately)



\## Current Features

\- View appointment records

\- Display appointment statuses

\- Create and manage appointments through the connected API

\- Support reminder delivery and retry status monitoring through the API



\## Running the Project

1\. Install Flutter and Dart.

2\. Open the `frontend` folder in Android Studio.

3\. Run `flutter pub get`.

4\. Start the Laravel API separately if API-backed features are required.

5\. Run the Flutter application in Chrome.



\## Submission Scope

This repository contains the initial Flutter frontend only. The Laravel backend is maintained separately and is not included in this submission.
